**WonderBits** is a SocialFi idle game built with **React**, combining virtual pets, island farming, and social interaction. The project was delivered across multiple web platforms, including a browser extension, PWA, and **LINE Mini Dapp** powered by the **Kaia** ecosystem.

I worked as a **Frontend Developer**, handling most of the frontend development for the project. My work focused on building the web-based game experience, adapting the frontend across different platforms and environments, and implementing localization for the game's user-facing experience.

Key areas of my work included:

- **Frontend Development** — implemented and maintained the web-based game experience using React.
- **Browser Extension & PWA** — adapted the game frontend for different web-based platforms.
- **UI/UX Implementation** — translated gameplay and interface designs into functional frontend experiences.
- **Localization** — implemented localization support for the game's frontend and user-facing content.
- **Platform Integration** — worked on the frontend experience across X and the project's broader Web3/social ecosystem.

The project presented a unique frontend challenge: delivering a consistent game experience across a browser extension, standalone web application, and LINE's Mini Dapp ecosystem while supporting multiple platforms and languages.
